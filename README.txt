CARDIOLOGY VA LEAD FINDER — MOBILE WEB APP V3

Deploy app.py, requirements.txt and README.txt to a Python web host.
Install: pip install -r requirements.txt
Start: gunicorn app:app

The app searches public web information for U.S. cardiology/medical practices,
VA/hiring signals, public business emails, phones and public social links.
It does not bypass logins, CAPTCHAs, anti-bot systems, or discover private emails.
